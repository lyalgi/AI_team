Методология внедрения: 6 шагов

Для каждой роли, которую хотим автоматизировать — идём по этим шагам по порядку.
1
Описываем полный функционал роли

Что сотрудник делает каждый день, каждую неделю, каждый месяц. Без этого нельзя понять что автоматизировать. Опросник в этом документе — инструмент для этого шага.

2
Составляем матрицу дня

Разбиваем задачи по трём ритмам: ежедневно / еженедельно / ежемесячно. Это определяет архитектуру: что идёт в утренний бот, что в еженедельный скрипт, что в агент по вызову.

3
Разбиваем по сложности реализации

Быстро (1-2 дня): чистая автоматизация, данные есть, алгоритм простой. Средне (3-5 дней): нужна агентная логика или интеграция с API. Пока непонятно: оставляем на потом, не блокируем на них всё остальное.

4
Пишем решение под каждый процесс

Для каждого блока определяем: откуда берём данные / какой алгоритм / в каком формате выдаём результат / кто получатель.

5
Собираем всё в единый Telegram-бот

Один интерфейс управления для роли. Утренние сообщения приходят сами, остальное — по командам. Никаких отдельных ссылок и интерфейсов.

6
Боевой тест

Берём одну роль, одну неделю работаем только через бота. Фиксируем: что работает, что не так, сколько времени занимает задача у бота vs у человека. Итог → решение масштабировать или доработать.

Что остаётся человеку

Переговоры

С поставщиками, фотографами, блогерами, партнёрами — ИИ не заменит живой коммуникации.

Стратегия

Квартальные и годовые решения о направлении бизнеса. ИИ готовит данные, человек решает.

Финальный выбор новинок

Данные даёт ИИ, но решение "запускаем / не запускаем" — всегда за человеком.

Нестандартные ситуации

Блокировки, претензии, конфликты — требуют суждения и контекста.

Управление командой

Найм финальный, увольнения, мотивация, разрешение конфликтов.

Креатив

Новые идеи, которых нет в данных. ИИ усиливает, но не заменяет.

Справка: как это всё устроено

Базовые понятия и ответы на частые вопросы.

Бот vs Агент vs Субагенты

ТипЧто умеетПример
БотОдно действие по расписанию или по командеДайджест новостей каждое утро
АгентПолучает цель → сам планирует шаги → вызывает инструменты → выдаёт результат"Проанализируй конкурентов" → сам идёт в МП Статс, читает отзывы, пишет ТЗ
СубагентыАгент запускает несколько задач параллельноУтренний брифинг: WB + Ozon + остатки собираются одновременно, потом сводятся в одно сообщение

Нужны ли подписки каждому сотруднику?

Для всех ботов и агентов — нет. Достаточно одного API-ключа Anthropic. Платите за токены (за использование), не за людей. Все автоматизации работают от одного ключа.


Для личного использования (когда человек сам хочет общаться с ИИ — писать промты, анализировать что-то руками) — тогда нужна личная подписка. По желанию, не обязательно.


Практическое решение: API-ключ для всех автоматизаций (один), подписки — только тем, кто реально будет пользоваться лично каждый день.

Важные предупреждения (из опыта других)

Проблема VPN. Claude нужен VPN, WB не работает с VPN. Это нужно решать на уровне сети до того, как раздавать доступы команде — иначе у каждого будет своя головная боль.


Блокировки аккаунтов Anthropic. Регистрацию лучше централизовать и отработать один рабочий способ — не пускать каждого разбираться самому.


Скиллы для личного использования. Если даёшь команде доступ к Claude напрямую — написать кастомные инструкции под каждую роль. Без этого люди не знают как им пользоваться.
